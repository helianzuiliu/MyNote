检查systemd的服务启动顺序

```bash
systemctl list-units --type=service
```

systemd服务启动是按照顺序启动的，其中一个服务启动等待时会导致其他服务启动阻塞

我的`systemd-networkd-wait-online.service` 服务启动失败会阻塞2分钟以上

# 解决方法

## 关闭服务自启动

```bash
systemctl disable systemd-networkd-wait-online.service
```

## 设置服务启动超时时间

### 打开配置文件

```bash
sudo nvim /etc/systemd/system/<service-name>.d/override.conf

sudo nvim /etc/systemd/system/systemd-networkd-wait-online.service.d/override.conf
```

### 在配置文件中加上超时时间

```txt
[Service]   
TimeoutStartSec=10s
```

### 重载服务配置

```bash
sudo systemctl daemon-reload
```
